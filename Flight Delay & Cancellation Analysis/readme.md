# ✈️ Airline Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing airline operations and flight cancellations using Power BI. The dashboard provides insights into flight performance, cancellation trends, cancellation reasons, and airport-wise route analysis.

The objective is to transform raw airline data into meaningful insights that can help understand operational performance and identify major reasons behind flight cancellations.

## 🎯 Project Objectives

- Analyze total flights and cancellation trends.
- Identify major reasons for flight cancellations.
- Compare cancellations across different airports.
- Analyze origin-to-destination routes.
- Understand which routes experience higher cancellations.
- Provide an interactive dashboard for exploring airline performance.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated columns and measures
- **Excel** – Data preparation (if applicable)

## 📊 Key KPIs

- Total Flights
- Total Cancelled Flights
- Cancellation Rate
- Total Completed Flights
- Cancellation by Reason

## 📈 Dashboard Analysis

### 1. Flight Overview
Provides an overview of airline operations through key performance indicators.

### 2. Cancellation Analysis
Analyzes flight cancellations based on different cancellation reasons to identify the major contributing factors.

### 3. Airport & Route Analysis
- Analyzes cancellations by Origin Airport.
- Compares cancellation reasons across airports.
- Examines Origin-to-Destination routes.
- Identifies routes with higher cancellation volumes.

### 4. Interactive Analysis
The dashboard allows users to explore data using interactive filters and slicers.

## 💡 Key Business Questions

1. What is the total number of cancelled flights?
2. Which cancellation reason contributes the most to cancellations?
3. Which origin airports experience the highest cancellations?
4. Which origin-to-destination routes have more cancellations?
5. How do cancellation reasons vary across different routes?

## 🚀 Key Learnings

- Data cleaning and transformation using Power Query.
- Creating calculated columns and DAX measures.
- Designing interactive Power BI dashboards.
- Analyzing flight cancellation patterns.
- Converting operational data into business insights.
